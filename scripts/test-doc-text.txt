顺序表 vs 单链表 顺序表：连续内存，支持随机访问、查询快；插入删除需移动元素、效率低。适合查询多、增删少、数据量稳定的场景。 单链表：离散内存，无需连续空间，插入删除 O (1) 效率高；不支持随机访问、查询慢。适合频繁增删、动态扩容的场景。

栈与队列区别及应用 栈：先进后出（LIFO）；队列：先进先出（FIFO）。均为受限线性表。 栈应用：函数递归调用、括号匹配、表达式求值；队列应用：消息队列、图 BFS 遍历、操作系统进程调度。

三种算法思想区别 分治：子问题独立无重叠，分而治之、合并结果； 贪心：每一步选局部最优，无回溯，不一定全局最优； 动态规划：子问题重叠、有最优子结构，记录子问题结果，避免重复计算，得到全局最优。

1、typedef struct LNode{

    int data;

    struct LNode *next;

}LNode;



LNode* reverseList(LNode *head)

{

    LNode *pre = NULL;

    LNode *cur = head;

    LNode *nextNode;

    while(cur != NULL)

    {

        nextNode = cur->next;  //保存后继结点

        cur->next = pre;       //反转当前结点指针

        pre = cur;

        cur = nextNode;

    }

    return pre;

}



2、int binarySearch(int a[], int left, int right, int target)

{

    while(left <= right)

    {

        int mid = left + (right - left)/2;

        if(a[mid] == target)

            return mid;

        else if(a[mid] < target)

            left = mid + 1;

        else

            right = mid - 1;

    }

    return -1;

}
